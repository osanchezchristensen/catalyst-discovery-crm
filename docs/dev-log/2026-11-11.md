## Phase 8 build (v0.11.0, rich-text notes)
**Branch:** `phase-8-rich-text-notes`

### Done
- The four note boxes use a TipTap editor (pinned to 3.32.1, explicit extensions only). Its toolbar has Bold, Underline, Bullet list and Numbered list, with `aria-pressed`, one tab stop and arrow keys between the buttons.
- Notes are stored as HTML limited to `<p> <strong> <u> <ul> <ol> <li>`. They are cleaned in the main process on save (zod transform) and on workspace import. See [ADR 0006](../decisions/0006-interview-notes-as-allowlisted-html.md).
- Migration v6 turns existing plain-text notes into paragraphs. Migrations can now be JS functions as well as SQL.
- Workspace files from before v6 have plain-text notes, so import converts them.
- CSV export writes notes as plain text, with lists as `•` and `1.` lines.
- Pastes keep only toolbar formatting (backlog #2). Checked in the app with a Word-style paste: links became text, the image and fonts and colors were dropped, and table cells became text.
- Highlighting text in a note still saves an insight as plain text.

### Decisions
- CSV bullets are `•` instead of the backlog's `-`: a cell starting with `-` trips the formula-injection guard, which would add `'` in front.
- Accepted [ADR 0006](../decisions/0006-interview-notes-as-allowlisted-html.md). Added TipTap to the CLAUDE.md stack.

### Not checked
- Screen reader pass on the toolbar (checked only that roles and labels are present).

### Next
- `ponytail-review`, then the PR.
