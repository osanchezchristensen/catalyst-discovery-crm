# Phase 3 (same day)

**Phase:** 3 (Evidence)
**Branch:** phase-3-evidence

## Done
- Hypotheses board (F5): six type sections, cards with a status chip (icon + word), risk, evidence tally and "Evidence suggests" when it differs. "Start with 3 templates" for an empty board. Dialog to edit, apply the suggestion, see linked interviews and delete.
- Evidence linking (F6): an Evidence card in the interview editor marks each hypothesis Not linked / Supports / Refutes / Neutral with a note. It saves with the interview (same autosave), one link per hypothesis.
- First screen tests: `jsdom` + `@testing-library/react` (dev only), a fake `window.api`, a regression test for the Phase 2 wiped-typing bug (confirmed it fails when the bug is put back), and an evidence-save test.

## Decisions
- Suggested status: Untested with no evidence; Testing until 5 Supports/Refutes; then Validated at 70%+ supports, Invalidated at 70%+ refutes, otherwise Mixed. Neutral verdicts never count toward the 5 or the share (changed during review so 1 Supports + 4 Neutral can't suggest Validated).
