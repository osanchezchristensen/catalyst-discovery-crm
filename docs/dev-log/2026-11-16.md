## Done
- Security audit for the release: run-2 (2026-11-12) had already audited `c43df12`, which is what `main` is now, so it was reused rather than run again. It had no confirmed findings and one needs-validation lead.
- Fixed that lead. An imported workspace file's `deleted_at` used to start the 30-day Trash clock, so a backdated value (or an honest teammate's delete from more than 30 days ago) purged the row at the next launch, along with its attachment files. Now a row that lands in Trash on import gets the local import time, and a row that was already in Trash keeps its own clock. Added a regression test, which fails without the fix.
- `npm audit --omit=dev`: 0 vulnerabilities.
- Bumped the version to 0.12.0.
